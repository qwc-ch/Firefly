# 问候卡壁纸目录

侧边栏「时间问候」卡片底部的装饰图来源，支持两种图，混放随意、都会被
Astro 图片管线（sharp）压缩为同源优化格式后再随机选用：

1. **构建期自动抓取（默认启用）**：`pnpm build` 时 `scripts/fetch-greeting-wallpaper.ts`
   会从随机图 API（`random-api.czl.net/pic/fj`）抽一张风景图下载到本目录，
   文件名固定为 `greeting-api.*`（gitignore，不入库）。每次构建换一张。
   手动触发：`pnpm greeting`。
2. **手动放置**：自己放 2~5 张横版图进本目录（webp/avif/jpg/png 均可，
   建议 1280px 宽左右，过大的图构建时会被压到 1280w）。

## 行为

- 目录为空（抓取也失败）时，运行时回退到随机图 API（单张 3MB+，不推荐长期这样用）；
- 正常情况下运行时只加载构建产物里的一张同源优化图（约 100~300KB），
  不再在运行时请求外部 API；
- 每次整页加载随机取一张；Swup 换页复用同一张，不重复下载。
